# organic_search_click_attribution：自然搜索点击归因

## 一句话定义

解释一次真实自然搜索中用户最终点击的结果，为何与此前可见需求和本次可见候选信息可能相关。

## 出题条件

future user behaviors 必须提供同一自然搜索请求的 query、完整可读曝光组和真实点击映射。完整曝光组包含同一搜索会话下按原排序可靠还原的全部曝光，不能因点击动作增删；它只是解释背景，不是待选答案或第二套候选。题面把曝光与动作合并成一份列表，每条明确标注 `[已点击]` 或 `[仅曝光、未记录点击]`，并披露对应证据编号；不再先单列点击集合，再展示一份不标注动作的曝光列表。每个 Note 展示标题、正文及所有非空图片描述、视频描述，暂不展示 OCR 或 ASR 字段。若只有点击行、缺完整曝光组、自然与广告点击无法区分或曝光内容不可读则不出题；不得把不完整的曝光组称为完整集合。

## 题目怎么问

先给出业务 instruction，再给出本次搜索的完整曝光结果，最后给输出要求。可解释 query 与点击结果的实体/场景匹配、历史需求延续和相近结果辨别；同时指出同样相关但仅曝光、未记录点击的结果和排序位置反证，内容或上下文不足则列为信息缺口。仅曝光、未记录点击只表示本次没有点击记录，不能写成“不喜欢”“不相关”或永久不会点击。没有可靠差异证据时应明确无法解释为什么点击这些结果而没有点击其他曝光结果。

## 可用信息

支持证据可来自历史搜索/内容需求，以及本次 query 与候选标题、正文或已验收属性。必须区分自然搜索点击、搜索广告点击和普通内容点击。点击表示本次选择查看，不等于喜欢、满意、收藏、购买或长期偏好。

## 回答与评分

输出 `result_summary`、`supporting_evidence`、`counter_evidence_or_gaps`、`alternative_explanations` 和 `confidence`。支持链引用真实 E/F 编号；若题面展示候选编号，答案必须沿用编号。证据不足时允许 `supporting_evidence=[]`、明确写“当前证据不足以解释候选间差异”并给 `confidence=low`。

逐项按 `0/0.5/1` 评分：点击集合忠实度、query/candidate 与证据对应、自然与广告动作区分、未点击语义边界、近邻反证、不确定性和协议遵循；各项取宏平均。

## 可选变化

难度来自同请求相近候选、query 歧义、历史需求转折和排序/内容证据冲突；不得靠缺曝光候选集合或随机无关候选。

## 种子提示词

题面会先给出冻结的可见历史，并明确披露预测窗口内一次自然搜索的完整曝光结果，其中逐条标明已点击或仅曝光、未记录点击。请只解释已发生点击与此前可见行为之间可能有哪些证据联系，不要再次预测、选择或改写结果。重点检查 query、曝光内容、排序位置和可见历史的联系；点击不等于满意、深度兴趣或购买，仅曝光、未记录点击也不等于不喜欢。分别说明支持证据、反向信号或信息缺口、时间关系、其他可能解释和结论置信度；证据很弱时，明确写当前历史无法解释该结果。这里的归因只是可见证据上的联系，不是因果证明。不得补输入外实体、动机、价格、身份或经历，不得升级曝光、浏览、收藏、加购、下单与成交的动作含义。
## 不出题/不合格

- 把未点击候选写成不喜欢或不相关；
- 把点击升级为满意、收藏或购买；
- 只有点击结果、没有同请求完整曝光候选仍要求比较归因；
- 混用自然搜索点击与搜索广告点击。
- 与预测同一搜索会话点击集合的 objective 子题组合并泄漏答案。
