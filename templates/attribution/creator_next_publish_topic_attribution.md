# creator_next_publish_topic_attribution：下一篇发布主题归因

## 一句话定义

解释创作者未来窗口内真实发布的主题集合，与此前可见创作内容和表达变化之间的证据联系。

## 出题条件

来源 objective 是 `creator_next_publish_topic`；两者都处理完整预测窗口内全部有效本人发布 Note，并在同一明确粒度上形成去重主题集合。future user behaviors 必须包含这些发布，且标题、正文或已验收 taxonomy 足以确定主题。题面披露去标识化主题集合 `[F……]`；原始发布事件、Note 内容和主题抽取证据留在评分侧。若窗口不完整、内容不可读或主题只能靠外部知识猜测则不出题。

## 题目怎么问

有联系时用历史发布和第一方文本建立支持证据，并区分长期稳定主题、近期动态和一次性尝试；反证包括此前从未发布该主题、近期持续转向另一方向或只有他人内容互动。无可靠联系时把主题来源和创作原因不可见列为信息缺口，并明确历史无法解释该发布主题。不得编造选题原因、创作灵感、合作、流量目标、商业动机或平台策略。

## 可用信息

Student 只使用可见的历史发布、第一方文本和 `[F……]` 结果。可检查稳定创作主题、系列延续、近期主题切换、用词与内容对象变化。结果只证明下一篇真实发布了该主题，不证明创作者长期定位、商业计划或个人经历。

## 回答与评分

输出 `result_summary`、带 E/F 引用的 `supporting_evidence`、`topic_evolution`、`counter_evidence_or_gaps`、`alternative_explanations` 和 `confidence`。无变化链时 `topic_evolution=[]`；证据不足时允许 `supporting_evidence=[]` 并给 `confidence=low`。

逐项按 `0/0.5/1` 评分：主题集合复述、各主题的历史发布与证据对应、主题粒度一致、时间演化、反证与不确定性、协议遵循；多个主题先逐项评分再取宏平均。难度来自相邻主题、系列内容与新尝试冲突、长期/近期转折和第一方文本跨时间变化；不能靠模糊宽主题或超长正文。

## 可选变化

可以改变已披露主题数量、历史创作稳定度和近期转向强度，但不能补写选题原因、长期定位或平台策略。

## 种子提示词

题面会先给出 <user behaviors>，并明确披露预测窗口内已经发生的“创作者下一篇真实发布主题集合”。请只解释该结果与 user behaviors 之间可能有哪些证据联系，不要再次预测、选择或改写结果。重点检查本人作品主题和时间演化；不得把互动过的他人内容当作创作者作品。分别说明支持证据、反向信号或信息缺口、时间关系、其他可能解释和结论置信度；证据很弱时，明确写当前历史无法解释该结果。这里的归因只是题内证据上的联系，不是因果证明。不得补输入外实体、动机、价格、身份或经历，不得升级曝光、浏览、收藏、加购、下单与成交的动作含义。
## 不出题/不合格

- 把下一篇主题改写成创作动机或未来长期规划；
- 用用户消费的他人内容冒充本人创作；
- 从主题推断身份、经历、收入或合作关系；
- 遗漏题面披露的部分真实主题，或把单次结果扩写为长期定位。
- 与预测同一主题集合的 objective 子题组合并泄漏答案。
