# future_commercial_trajectory_attribution：跨域商业轨迹归因

## 一句话定义

解释题面已披露的一条真实商业行为轨迹，指出 user behaviors 中哪些证据能支持、反驳或无法解释该轨迹。

## 出题条件

- future user behaviors 中存在顺序确定、实体可对齐的真实商业阶段链；至少包含两个阶段。
- 题面只披露去标识化的阶段、顺序和必要实体，不披露其他未来证据。
- 阶段缺失、时间顺序不确定或跨实体无法对齐时不出题。

## 题目怎么问

题面固定按“业务 instruction → 已发生结果 → 输出要求”的顺序呈现。要求解释轨迹中的关键转折、user behaviors 支持证据、反证或缺口，并显式给出不确定性。题目不重新预测 `[F]`，也不要求推断平台策略或用户内心原因。

## 可用信息

Student 只看到冻结的 `user behaviors`、问题与 `[F]` 结果。完整 `future user behaviors` 仅供 Scorer 核验。不得补写“典型漏斗”中没有发生的步骤；没有某阶段不等于厌恶、流失或系统失误。

## 回答与评分

支持有界自然语言、编号要点、阶段表格或 JSON；协议必须把“已发生结果”和“解释证据”分开。

按 `0/0.5/1` 评分：结果忠实度、阶段/实体对齐、基于 user behaviors 的证据、时间一致性、反证与信息缺口、不确定性、指令遵循；取宏平均。

## 可选变化

user behaviors 同时出现长期消费方向、近期 query 与跨来源弱证据，而 `[F]` 是一条真实但不完整的商业阶段链；答案能解释证据，也明确哪些阶段原因不可见。

## 种子提示词

题面会先给出冻结的可见历史，并明确披露预测窗口内已经发生的“真实多阶段商业行为轨迹”。请只解释该结果与此前可见行为之间可能有哪些证据联系，不要再次预测、选择或改写结果。重点检查搜索、内容互动、商品动作和成交之间的时间关系；不得补未发生阶段或无可靠标识关联的跨事件链。分别说明支持证据、反向信号或信息缺口、时间关系、其他可能解释和结论置信度；证据很弱时，明确写当前历史无法解释该结果。这里的归因只是可见证据上的联系，不是因果证明。不得补输入外实体、动机、价格、身份或经历，不得升级曝光、浏览、收藏、加购、下单与成交的动作含义。
## 不出题/不合格

- 重新预测或修改 `[F]`；
- 编造未发生阶段、成交原因、平台推荐机制；
- 把曝光、点击直接升级为购买意图；
- 与任何预测同一 `[F]` 结果的题目组合，导致答案泄漏。
