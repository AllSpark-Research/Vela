# organic_search_post_click_stage_attribution：搜索点击后阶段归因

## 一句话定义

解释题面已披露的真实搜索点击后最深阶段，以及 user behaviors 中的搜索和行为证据与该结果之间的联系。

## 出题条件

- 同一搜索会话中 query、clicked Note 与点击后阶段可以可靠对齐。
- `[F]` 只披露实际最深阶段；其他未来行为仍隐藏。
- 会话窗口不完整、Note 对齐不唯一或阶段字段缺失时不出题。

## 题目怎么问

要求使用 `[E]` 解释 `[F]`，列出支持证据、相反证据和不可见信息。不得要求推断平台排序因果或把阶段解释成稳定画像。

## 可用信息

Student 只看冻结的 `user behaviors` 与 `[F]`。未进入更深阶段只表示本次未观察到，不等于不喜欢；点击也不能升级成购买意图或候选质量结论。

## 回答与评分

支持编号自然语言、两列表格或 JSON；必须保留阶段原名和 `E/F` 引用。

按 `0/0.5/1` 评分：结果复述、实体对齐、时间一致性、证据支持、反证/缺口、非因果边界、指令遵循。

## 可选变化

user behaviors 有同类 query 和内容互动，但对电商深度的历史证据互相冲突；答案解释其相关性并保持低置信。

## 种子提示词

题面会先给出冻结的可见历史，并明确披露预测窗口内已经发生的“搜索点击后的真实最深阶段范围”。请只解释该结果与此前可见行为之间可能有哪些证据联系，不要再次预测、选择或改写结果。重点检查 query、候选内容和前后行为；阶段范围不能写成主观满意度、确定意图或平台排序因果。分别说明支持证据、反向信号或信息缺口、时间关系、其他可能解释和结论置信度；证据很弱时，明确写当前历史无法解释该结果。这里的归因只是可见证据上的联系，不是因果证明。不得补输入外实体、动机、价格、身份或经历，不得升级曝光、浏览、收藏、加购、下单与成交的动作含义。
## 不出题/不合格

- 重新预测 `[F]`；
- 把未加购写成不喜欢；
- 由一次点击推断稳定购买意图；
- 与同一结果的 objective 同组。
