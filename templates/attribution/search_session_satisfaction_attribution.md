# search_session_satisfaction_attribution：自然搜索会话响应深度归因

## 一句话定义

解释题面已经披露的自然搜索会话响应深度，与此前可见搜索需求和行为变化之间有哪些证据联系。

## 出题条件

结果必须由搜索会话聚合口径下同一会话的完整聚合字段生成，并以 `[F……]` 披露 query 与真实档位。观察历史
使用 `[E……]`。若 query、曝光机会、互斥档位或窗口不完整，则不出题。

## 题目怎么问

题目必须说明结果已经发生、不需要再次预测；要求引用 E/F 证据，分别给出支持联系、反证/缺口、替代解释
和置信度。不得与解释同一会话的 来源客观题 放进一个 复合题。多个 query 并列时分别评分。

## 可用信息

答案只解释可见历史与已发生档位之间的可能联系。未点击不等于不满意、不喜欢或结果质量差；普通点击不
等于满意，深层响应也不证明 query 的全部需求已满足。入口、排序方式和类目只能作为可见上下文，不能
单独证明结果原因。

## 回答与评分

支持编号要点、表格、JSON 或有界自然语言。每条支持证据 同时引用 E ref 和 F ref；若没有可靠
联系，支持数组为空，缺口第一项写“当前证据无法解释该结果”，置信度为 low。

1. **结果忠实度**：准确复述 query 和响应档位，不增加具体点击对象；
2. **证据对应**：E/F 编号真实存在，历史事实可核对；
3. **搜索场景边界**：区分自然搜索、广告搜索和普通内容互动；
4. **动作边界**：未点击、普通点击、好点击/深层互动不互相升级，也不等同主观满意度；
5. **反证与缺口**：考虑 query 歧义、入口差异、历史冲突和候选内容不可见；
6. **替代解释与置信度**：排序、候选质量或外部情境只能写为未知可能，不能写成事实；
7. **协议遵循**：覆盖全部披露结果及题面要求字段。

## 可选变化

使用长期强需求但本次无点击、过去只有浅点击但本次深层互动、相似 query 的相反档位和搜索入口变化提高
难度。候选曝光集合 不可见时，模型应把它列为缺口，而不是编造结果质量。

题面披露某次主动搜索“有曝光未点击”；user behaviors 中存在同主题历史点击，也存在近期需求转移。合格答案应
同时说明主题延续与行为冲突，并承认缺少本次候选内容，不能断言用户不满意。

## 种子提示词

题面会先给出冻结的可见历史，并明确披露预测窗口内已经发生的“自然搜索会话的真实响应深度”。请只解释该结果与此前可见行为之间可能有哪些证据联系，不要再次预测、选择或改写结果。重点检查搜索 query 与后续动作的可见联系；响应深度不能写成主观满意度。分别说明支持证据、反向信号或信息缺口、时间关系、其他可能解释和结论置信度；证据很弱时，明确写当前历史无法解释该结果。这里的归因只是可见证据上的联系，不是因果证明。不得补输入外实体、动机、价格、身份或经历，不得升级曝光、浏览、收藏、加购、下单与成交的动作含义。
## 不出题/不合格

- 再次预测已披露的档位；
- 把“有曝光未点击”写成不喜欢或结果差；
- 没有候选曝光集合 却解释具体未点击 Note；
- 混用自然搜索和搜索广告指标；
- 用先后关系、入口或类目相似直接声称因果。
