# comment_target_note_attribution：评论目标笔记归因

## 一句话定义

解释用户未来真实评论的目标笔记，为何与此前可见内容兴趣和表达行为可能相关。

## 出题条件

来源 objective 是 `comment_target_note`；两者都以预测窗口内全部有效评论事件对应的去重 `note_id` 集合为准。只有 future user behaviors 中存在有效事件，且每个待解释目标都能稳定关联可读目标笔记时才出题。题面可披露一个或多个目标笔记 `[F……]`；每张 Note 卡展示标题、正文及所有非空的图片描述、视频描述，暂不展示 OCR 或 ASR 字段。评论事件、目标关联和 future user behaviors 中的最小证据 留在评分侧。只有评论文本而无可靠目标 note、目标内容不可读或窗口不完整时跳过。

## 题目怎么问

有联系时列出可核对的支持证据，同时保留相邻主题、相反观点、时间间隔或表达风格不一致等反证。若目标笔记此前从未出现、只有宽主题重合或评论动机不可见，应明确证据缺口并降低置信度。没有可靠联系时，支持证据留空并写“当前证据无法解释该结果”。不得编造评论动机、态度或具体评论内容。

## 可用信息

Student 只能引用冻结历史 `[E……]` 和已披露结果 `[F……]`。重点检查同主题或同作者的重复接触、此前评论/收藏/分享、第一方表达和近期兴趣变化。评论表示用户对该笔记执行了评论动作，不等于赞同内容，也不能把笔记中的经历写成用户经历。

## 回答与评分

按每个已披露目标分别输出 `result_summary`、`supporting_evidence`、`counter_evidence_or_gaps`、`alternative_explanations`、`confidence`。每条支持链同时引用 E ref 与对应 F ref；`confidence` 只用 `high|medium|low`。证据不足时合法输出为 `supporting_evidence=[]`、明确说明当前证据无法解释，并给 `confidence=low`。

每个目标逐项按 `0/0.5/1` 评分：结果复述、证据可核对性、评论动作边界、反证/缺口、替代解释与置信度、协议遵循；先算目标内 rubric，再对目标取宏平均。难度来自同主题近邻笔记、同作者不同笔记、观点冲突和跨时间表达变化；无关长文本不构成难度。

## 可选变化

可以改变已披露目标的数量、历史证据强弱和反证类型，但不能重新预测目标、补写评论内容或改变 E/F 引用协议。

## 种子提示词

题面会先给出 <user behaviors>，并明确披露预测窗口内已经发生的“真实评论目标 Note 集合”。请只解释该结果与 user behaviors 之间可能有哪些证据联系，不要再次预测、选择或改写结果。重点检查 Note 主题、作者和既往互动联系；评论结果不能证明长期兴趣或确定动机。分别说明支持证据、反向信号或信息缺口、时间关系、其他可能解释和结论置信度；证据很弱时，明确写当前历史无法解释该结果。这里的归因只是题内证据上的联系，不是因果证明。不得补输入外实体、动机、价格、身份或经历，不得升级曝光、浏览、收藏、加购、下单与成交的动作含义。
## 不出题/不合格

- 重新预测已给出的目标笔记；
- 把评论写成点赞、关注、购买或认同；
- 编造评论内容、动机或用户身份；
- 与预测同一目标笔记的 objective 子题组合并泄漏答案。
