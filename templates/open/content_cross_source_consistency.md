# content_cross_source_consistency：内容跨来源一致性判断

## 一句话定义

比较同一 Note 的文本、OCR、ASR 与视觉描述，识别跨源支持、单源陈述、表面冲突和证据不足。

## 出题条件

- 同一 Note 至少有两个非空且可比较的内容来源。
- Composer 先从 user behaviors 中抽出少量可核验主张，再要求逐条判断。
- 来源只讲不同方面、无法比较或 OCR/ASR 严重损坏时，必须允许 `unknown`，不能凑冲突。

## 题目怎么问

给出有编号的主张和来源证据包，要求分类为 `cross_source_supported`、`single_source_only`、`apparent_conflict` 或 `unknown`，并引用证据。

## 可用信息

只使用 `user behaviors`，**不保存 future user behaviors**，也不以外部知识裁决真伪。不同来源描述不同侧面不等于矛盾；OCR/ASR 噪声需要降置信。

## 回答与评分

支持标签表、编号自然语言、JSONL 或键值映射；必须为每条主张保留证据和不确定性。

逐主张评分：主张及实体准确性、来源覆盖、证据引用可定位性、一致/冲突/未知标签正确性、时间与对象对齐、冲突边界、噪声过滤、合理 abstain 和协议遵循；再取宏平均。多源事实一致且引用完整得 1；结论基本正确但漏一处来源、时间差或次要冲突得 0.5；跨对象拼接、把缺失当一致、隐藏冲突或无证据下强判得 0。编造来源、引用不存在的证据或用外部知识裁决冲突属于硬失败。

## 可选变化

标题与正文共同支持主题，OCR 单独出现价格，ASR 与正文在规格上有表面差异；答案区分支持、单源和冲突，而不是给整篇一个总标签。

## 种子提示词

围绕题面列出的主张，比较同一 Note 的正文、OCR、ASR 和视觉描述，逐条判断为多源支持、仅单源陈述、表面冲突或证据不足，并引用对应来源。来源文本可能有噪声；不得让任一来源自动覆盖其他来源，不得用外部知识裁决冲突，不能确认时应保留 unknown。输出必须覆盖全部指定主张。
## 不出题/不合格

- 用外部知识决定真伪；
- 把互补信息写成冲突；
- 忽略 OCR/ASR 噪声；
- 输出单个整篇标签，无法逐主张评分。
