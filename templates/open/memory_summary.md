# memory_summary：from-scratch Layer 0 原子 Memory 写入

## 一句话定义

只根据冻结的 `user behaviors`，每次从空白结果开始，写出以后仍可能有帮助、且值得持久化的原子用户 Memory。

## 出题条件

只有同时满足以下条件时才出题：

1. `user behaviors` 中至少有一条具有持续价值的明确事实、稳定倾向、当前目标、约束或近期变化；
2. 信息来自用户自述或多次、较强且相互一致的行为证据，能够与一次性曝光和弱触达区分；
3. 时间范围可由输入确定，或答案可以诚实标记“当前”“近期”“时间未知”；
4. Composer 能为本题的条数、篇幅、字段与证据要求写出可执行 rubric。

若只有一次曝光、偶然点击、低价值流水、无法归属给用户的他人内容或互相冲突且无法安全表达的信息，
则本模板返回空结果，不硬写 Memory。

## 题目怎么问

Composer 从全局记忆、稳定信息、当前目标、约束、近期变化、选择性记忆、冲突与不确定性中选择一个
或数个自然相关目标，明确：

- 最多保留多少条或总字数上限；
- 是否区分稳定信息、当前目标、约束和近期变化；
- 是否要求重要性排序、证据编号、时间范围或证据性质；
- 冲突、未知和弱证据如何表达；
- 本次使用自然语言、要点、JSON、键值表或 记忆卡 中哪一种答题协议。

题面不能只把同一答案机械换壳；协议变化必须真正改变指令遵循要求。

## 可用信息

- 唯一事实源是逐字冻结的 `user behaviors`；第一版不依赖 `future user behaviors`；
- 用户明确自述强于行为推断；弱行为只允许谨慎表达或直接省略；
- 曝光、浏览、搜索和单次互动不能升级为长期偏好、身份或真实经历；
- 他人笔记内容只表示用户接触过相关内容，不属于用户本人经历；
- 敏感身份、健康、婚恋、年龄、性别、职业和城市等信息，只有输入中明确且来源合格的用户自述才可写；
- 同一事实重复出现时压缩去重；冲突证据并列并表达不确定性，不强行裁决；
- 每条 Memory 原子化，只写一个可独立理解的事实或倾向，并保留可证明的时间边界；
- 输入不接收记忆 ID、记忆库快照或旧记忆列表；输出不引用这些对象，只写新筛选的原子条目。

## 回答与评分

- 不超过指定字数的自然语言 Memory；
- 按重要性排序的编号要点；
- `stable_information/current_goals/constraints/recent_changes/uncertain` JSON；
- 键值表：Memory、时间范围、证据性质、置信度；
- 记忆卡：每张卡片只含一条原子 Memory、时间范围和 证据依据。

协议由题面明确。JSON 或卡片中的 topic 必须由输入动态产生，不能变成固定垂类白名单。

Scorer 只读取题面允许使用的、来自 user behaviors 的证据，并按 0 到 1 评估：

1. **Grounding**：每条 Memory 都能在 user behaviors 中找到明确证据，不引入外部事实；
2. **Salience**：只保留以后可能有帮助的高价值信息，过滤一次性曝光、弱触达和低价值流水；
3. **Temporal consistency**：正确区分稳定信息、当前目标和近期变化，保留可证明的时间范围；
4. **Uncertainty**：弱证据、冲突和未知被如实表达，不强行确定；
5. **Compression**：事实原子化、去重且简洁，不重复抄写整段历史；
6. **Instruction following**：满足题面要求的字段、条数、排序、证据引用和答题形式。

不存在“必须写满”的要求。没有合格 Memory 时，按协议明确输出空结果是正确答案。
高价值事实选择、时间范围、证据性质、原子化表达和必要不确定性全部正确得 1；核心 Memory 正确但漏少量重要约束、时间边界或压缩不充分得 0.5；编造事实、把弱触达写成稳定偏好、遗漏明显当前目标或大段复述流水得 0。Grounding、Salience、时间一致性和信息完整性为主维度，格式只占较低权重。使用未披露的未来信息、敏感身份推断或把综合 persona 当 Memory 属于硬失败。

## 可选变化

可以通过长时间跨度、稳定与阶段性信息并存、重复事实去重、可见冲突、严格条数/字数限制和不同证据
性质提高难度；不得靠无关历史、外部知识或伪造旧记忆状态增加复杂度。

- 多次行为与明确自述共同支持一个稳定偏好，同时近期出现一个具体目标；答案分别写为稳定信息和当前目标。
- 同一主题在两个时间段出现相反信号；答案保留双方证据并标记当前状态不确定。
- 历史很长但大多是一次性曝光；答案只保留少量高价值 Memory，不为满足条数凑弱证据。

## 种子提示词

只根据给定的可见用户历史，从空白结果开始筛选并写出未来可能有帮助、值得持久保存的原子 Memory。区分稳定信息、当前目标、约束、近期变化以及不确定或冲突信息；重复事实去重，保留可证明的时间边界，弱曝光、一次性流水和低价值信息不写。不得引入外部事实、生成宽泛用户画像，也不得读取或管理任何已有 Memory。没有合格 Memory 时输出空结果。
## 不出题/不合格

- 把“看过某篇育儿笔记”写成“用户已经育儿”；
- 把一次搜索、曝光或点击写成稳定偏好；
- 把他人笔记中的地点、职业或经历写成用户事实；
- 输出对旧记忆的增删改、合并、过期或其他治理动作；
- 生成宽泛用户画像，而不做选择性持久化；
- 忽略条数、字数、字段、证据或冲突表达要求。
