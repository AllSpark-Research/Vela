# behavior_change_summary：可见行为变化总结

## 一句话定义

比较同一个冻结 `user behaviors` 内较早与较近两部分的同口径行为，证据化总结增加、减少、稳定、转向或无法判断的变化。

## 出题条件

- `user behaviors` 是本题唯一的动态输入；其中必须有足够时间戳，能在同一段历史内划分互不重叠的较早证据与较近证据。
- 两部分都有足够同口径事件或可验证聚合；来源覆盖不完整时必须允许“无法判断”。
- Composer 只能比较 user behaviors 中真实存在的动作、对象、来源与计数，不制造缺失期，也不得要求第二份 user behaviors、跨目录历史或额外状态。

## 题目怎么问

从同一个 `user behaviors` 中明确较早/较近证据的时间边界、比较对象和单位，要求列出变化结论及对应证据。可同时比较多个目标，但每个目标独立评分。

## 可用信息

只使用同一个 `user behaviors` 内的时间戳和行为事实，**不保存 future user behaviors**。日志没有出现不等于行为下降；曝光、点击、搜索不得升级为稳定偏好或身份。

## 回答与评分

支持自然语言、编号、表格、键值或 JSON；必须写清同一段历史内的较早/较近边界与未知项。

按目标分别评分：较早/较近窗口划分、事实与计数准确性、变化方向及幅度、同一目标跨时间对齐、跨来源动作边界、核心变化覆盖、反向信号与不确定性、压缩去重和协议遵循；多个目标取宏平均。窗口、事实、方向和核心覆盖完全正确得 1；变化趋势基本正确但边界、幅度或次要证据不完整得 0.5；时间倒置、跨对象拼接、把曝光升级为强行为或凭空补原因得 0。使用未来窗口、编造计数或把无变化写成确定变化属于硬失败。

## 可选变化

同一个 `user behaviors` 的较早与较近证据中，搜索主题、Note 深互动与加购行为出现不同方向变化；答案不把日志空白误判为下降。

## 种子提示词

只在题面给出的同一个冻结可见片段内，按明确的较早/较近时间边界和同一统计口径比较一个或多个目标，判断增加、减少、稳定、转向或无法判断，并为每个结论给出对应证据。记录缺失、覆盖范围变化和真实行为变化必须区分，频次变化不能被解释成确定动机。不得使用片段之外的信息。输出必须写清时间边界、比较单位和未知项。
## 不出题/不合格

- 使用 future user behaviors 或预测下一阶段；
- 要求上游再提供第二份 user behaviors、外部历史文件或存量状态；
- 用不同口径窗口直接比较；
- 把未记录写成减少；
- 把变化总结写成稳定人格画像。
