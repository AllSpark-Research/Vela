# creator_content_portfolio_summary：创作者内容组合总结

## 一句话定义

只根据用户本人已发布的 Note，总结其可见内容主题、内容形态、更新组合和已观察表现。

## 出题条件

题型是只使用 user behaviors 的分组总结。gold 由用户自发 Note 的标题/正文、图文/视频形态、发布时间和题面明示的已观察表现指标组成。表现只陈述可见数值或相对差异，不归因为内容质量或用户喜好。

1. user behaviors 中至少有两篇能确认由用户本人发布的 Note；
2. 每篇至少有可读标题、正文、形态或发布时间中的两项；
3. 需要跨 Note 分组、比较或压缩，而不是复述一篇 Note。

只有一篇可读作品、只有 Note ID，或无法确认作者归属时，Composer 返回空结果。

## 题目怎么问

Composer 选择主题组合、形态组合、发布节奏和已观察表现中的 2至4 个维度，要求输出分组、代表 Note 证据和不确定性。题面明示指标口径和篇幅上限。

## 可用信息

- user behaviors 使用冻结的原始行为；不使用 future user behaviors。
- 只使用“发布笔记”等明确自发行为与其笔记内容字典中的内容；不混入被浏览、收藏或评论的他人 Note。
- 主题、形态和时间分布可跨 Note 归纳；未显示的视觉风格、制作流程和创作动机不推断。
- 点赞、收藏、评论等表现只在输入明示时使用；不由高低表现推断受众成分或因果。

## 回答与评分

- 创作组合表；
- 主题 portfolio cards；
- 有字数上限的组合摘要 + 代表 Note 清单。

1. **作品归属**：只统计用户本人已发布 Note。
2. **主题分组**：分组与可见内容一致，近义主题合理合并。
3. **形态与节奏**：图文/视频、时间分布与发布频率只按可见事实描述。
4. **表现正确性**：指标数值或相对差异准确，无因果或受众推断。
5. **非 persona 边界**：不推断创作者身份、人格、职业、动机或未来规划。
6. **协议遵循**：维度、字段、篇幅、证据引用和缺值符合题面。

本人作品归属、主题分组、内容形态、时间节奏、表现信息和代表作品覆盖全部准确得 1；主体正确但少量作品遗漏、近义主题合并不充分或非关键指标说明不完整得 0.5；混入他人作品、编造发布频率/表现、由互动推断身份动机或遗漏主要创作方向得 0。作品归属、信息准确性和 portfolio 完整性为主维度，格式只占较低权重。使用未披露的未来信息、敏感身份或因果受众推断属于硬失败。

## 可选变化

可使用跨时间主题变化、同主题多形态、近义主题合并、表现指标量纲不一或局部缺失提高难度。不得混入他人 Note、用外部知识补内容类目、或由表现反推人格/受众。

用户自发 Note 包含多篇图文菜谱和少量视频厨具使用记录。答案分成两个内容组，如实记录形态、发布时间与可见表现，不推断“职业美食博主”或粉丝偏好。

## 种子提示词

只根据题面中用户本人已经发布的 Note，归纳可见的作品主题、内容形态、发布时间变化和题面要求的已观察表现，并为每个结论引用代表作品。近义主题合理合并，局部缺失与时间变化如实保留。不得混入用户互动过的他人内容，不得由稀疏作品或表现指标推断创作者职业、人格、受众、动机或未来规划。
## 不出题/不合格

- 把用户收藏的他人 Note 算入创作组合；
- 由高点赞推断某主题“更受女性用户喜欢”；
- 将作品组合写成创作者人格画像。
