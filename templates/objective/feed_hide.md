# feed_hide：完整单题模板

## 一句话定义

从未来笔记候选中预测用户会明确点击“不感兴趣”的项目。

## 出题条件

1. future user behaviors 中至少有一条带 `note_id` 且标题或正文可读的明确 hide；
2. gold 是预测窗口内所有被 hide 的 note 去重集合；正例通常稀疏，不按数量封顶；
3. 候选卡统一显示标题、正文及所有非空图片描述、视频描述，暂不展示 OCR 或 ASR 字段，任何因上下文预算进行的截断都必须显式标记；
4. Note 候选去重后最多 30 张；候选构造不得依据 hide gold 裁切，无法在 30 张内保留完整任务语义时不出题；
5. 全时间线 action 为未映射 `interact` 的笔记进入不确定桶，既不作 gold 也不作干扰；
6. 可靠干扰少于 2 个、future user behaviors 不完整或没有可读正例时不出题；可靠干扰数量少于目标数量时使用全部现有候选，不因此丢题。

干扰只取该用户点击或长看过、全时间线从未 hide、也从未落入 `interact` 不确定桶的笔记。长看过的
笔记是最强对照，因为题目需要区分口味两端。此任务不接跨用户池；所有候选必须是同格式 note 卡，
并排除重复 note、future user behaviors 中的 gold 和任何曾 hide 的 note。

## 题目怎么问

Composer 使用冻结的完整 Note 卡生成明确的 hide 预测 question，写出预测窗口、集合式多选和证据要求；
候选去重后最多 30 张，作答数量不设固定上限。
它必须把候选编号归一化、hide gold、不确定桶排除和理由评分放进隐藏评分配置，不能用 future user behaviors
负反馈反向改写 user behaviors 或题面。

## 可用信息

Student/Teacher 不得看到 future user behaviors 中的 hide 动作、`is_gold` 或候选来源。没有 hide 只能解释为窗口内未观察到
明确负反馈，不能写成喜欢；点击和长看也不能被硬编码为永久喜欢或永不 hide。

## 回答与评分

答案使用 `{"choice": [编号, ...]}` 的去重候选编号集合。题面必须写清空集和候选外答案处理；Note 候选最多 30 张，作答数量不设固定上限。

1. 保存 note 编号映射、去重 hide gold、future user behaviors 中的最小证据和不确定桶排除记录；
2. 选择集合按 precision/recall/F1；若实例只有一个 gold，也仍允许集合协议并按集合评分；
3. 可见理由按证据对应关系单独评分，把“没互动”当“不感兴趣”需扣动作边界分；
4. 候选外 note、重复编号及缺少题面要求的理由按明示协议扣分。

## 可选变化

核心难度来自同主题但历史反应相反的 note、重复内容疲劳、近期口味变化，以及把长看过的强对照与
hide gold 混排；不得靠跨用户无关笔记、空卡片、正文长度差异或把未点击直接标负例提高难度。

user behaviors 中对某主题既有重复负反馈也有长看，future user behaviors 中对一条内容相近的 Note 执行了 hide；候选同时包含用户长看过的
同主题笔记，要求选择可能被明确 hide 的项并用 user behaviors 负反馈模式解释。

## 种子提示词

你要根据用户消息中给出的、截至观察窗口结束时可见的用户画像与行为记录，判断候选笔记中哪些会在题目指定的未来预测窗口内被该用户明确点击“不感兴趣”。只有明确的 hide 负反馈算正例；未点击、短停留、没有互动或一般低兴趣都不能直接当作“不感兴趣”。

候选项构成本题的封闭集合。请结合用户既有的内容口味、厌恶信号、重复内容疲劳和负反馈模式，选出所有可能成为正例的候选编号。只能使用当前消息中的可见事实，不得调用外部知识，不得补写窗口外的行为，也不得输出候选集合之外的内容。

请先基于输入中的可见证据分析候选项与未来行为的可能关系，再给出最终选择。证据不足时可以明确说明，不得补写输入之外的信息。

请先分析可见证据，再在本子题答案末尾给出且只给出一个包含 `choice` 的 JSON 对象，例如 `{"choice": [候选编号]}`。`choice` 必须是去重后的整数数组，只能选择题面候选。
## 不出题/不合格

- 用未点击、短停留或 `interact` 作为 hide gold/干扰；
- 加入跨用户随机 note，或候选一边有正文一边只有 ID；
- 要求预测类目厌恶，但 gold 只在具体 note 层；
- 把“窗口内未 hide”写成长期喜欢；
- 解释写得流畅就给高分，而忽略 hide 候选选错。
