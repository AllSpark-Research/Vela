# feed_engage_note：未来深度互动 Note 选择

## 一句话定义

根据冻结历史，从完整 Note 候选中预测未来会发生长看、点赞、收藏、评论或关注等深度互动的 Note 集合。

## 出题条件

- future user behaviors 至少有一条深度互动 feed 事件且 `note_id` 可读；
- gold 收齐窗口内全部合格 Note 后去重；
- 候选包含完整标题（`title`）、正文（`content`）及所有非空图片描述、视频描述，并至少有两个真实非 gold Note；暂不展示 OCR 或 ASR 字段。

## 题目怎么问

题面给出预测窗口和完整 Note 候选卡，要求选择窗口内所有真实深度互动目标；曝光和点击不算正例。

## 可用信息

hard distractor 优先取该用户曝光或点击过但未深度互动的 Note，不足时由冻结 Note 池补同格式候选。

## 回答与评分

答案使用 `{"choice": [编号, ...]}` 的去重编号集合，内容分采用集合 precision、recall、F1；候选最多 30 张完整 Note 卡，去重后仍不得超过该上限。

## 可选变化

可以使用同主题近邻 Note、同作者不同内容和长期、近期兴趣冲突调节难度，不得用卡片信息量差异制造捷径。

## 种子提示词

请根据题面给出的 <user behaviors>，从完整 Note 候选卡中预测指定未来窗口内会发生深度互动的 Note 集合。只有长看、点赞、收藏、评论或关注算正例；曝光和点击不等于深度互动。

先分析可见历史，再在本子题答案末尾给出且只给出一个 `{"choice": [候选编号]}`。`choice` 必须是去重整数数组，只能选择题面候选。

## 不出题/不合格

- future 没有可读 Note gold；
- 候选不是完整 Note 卡或少于两个合法非 gold Note；
- 把曝光、点击升级为深度互动；
- 泄漏 future 动作或候选 `is_gold`。
