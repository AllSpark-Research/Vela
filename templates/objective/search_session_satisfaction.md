# search_session_satisfaction：自然搜索会话响应深度预测

## 一句话定义

给定一条真实自然搜索 query，预测该会话在隐藏未来中达到的可观察响应深度。

## 出题条件

本任务只使用搜索会话聚合口径的同源会话字段，不假定其他搜索数据表的
同名搜索会话标识已可跨表连接。题面可展示搜索词、入口、
排序方式和类目；以下会话指标仅留在 future user behaviors：

1. **有曝光未点击**：曝光计数大于 0 且点击计数等于 0；
2. **有点击但无深层行为**：点击计数大于 0，同时好点击计数等于 0，且点赞、收藏、评论、分享、
   关注计数全部为 0；
3. **有好点击或深层互动**：好点击计数大于 0，或点赞、收藏、评论、分享、关注任一计数大于 0。

若字段缺失、计数冲突、没有真实曝光机会、query 不可读或窗口不完整，则不出题。页面停留时长和首次点击
时间可作为隐藏校验或附加数值目标，但在未核实单位与阈值前不得擅自改写三档 gold。

## 题目怎么问

Composer 在 question 中逐字定义三档，并说明预测窗口。单题可问一个 query，也可并列多个独立 query；
后者逐项评分后取宏平均。Composer 不能用本次搜索后的候选动作、页面停留或 future user behaviors 中的计数写理由，
也不能把广告会话统计混进自然搜索 gold。

## 可用信息

Student/Teacher 只看到冻结历史与待判断 query，不看到会话计数和响应档位。未点击只表示本次有曝光但未
选择，不等于不满意、不喜欢或 query 无需求；点击也不等于满意、收藏、加购或购买。自然搜索与广告搜索
必须区分。

## 回答与评分

支持单标签、编号表格、键值映射或 JSON。协议必须使用题面定义的三个标签，说明是否需要理由；理由只按
基于 user behaviors 的证据 单独评分，不能改变档位准确率。

1. 主分是逐 query 三分类 accuracy，多 query 时取宏平均；
2. 好点击或深层互动优先于普通点击，档位构造必须互斥；
3. 自然搜索、广告曝光/点击、普通内容互动混淆分别扣分；
4. 把未点击解释为负反馈或把点击升级为满意/购买，语义边界项为 0；
5. 协议明确要求的标签、编号和理由覆盖进入 instruction-following 分。

## 可选变化

使用相近 query 但不同历史响应深度、强历史需求却本次无点击、弱历史信号却出现好点击，以及主动输入与
搜索建议/默认词入口差异提高难度。不得用字段缺失、跨表错连或含义不明的停留阈值制造难度。

user behaviors 中同类 query 既有快速点击也有收藏/分享，本题给出一个新的相近 query，要求判断其未来会话落入
哪一档；答题者需要区分普通点击与深层响应。

## 种子提示词

题面会提供冻结的可见历史、明确的预测窗口以及题目所需的候选或状态定义。请根据冻结历史和题面中的 query，预测各搜索会话会落入“有曝光未点击、点击但无深层行为、有好点击或深层互动”中的哪一档。响应深度只是行为代理，不等于主观满意度、购买意图或长期偏好。只使用题面给出的信息，不得新增、删除、改写候选或使用未披露的未来结果。
## 不出题/不合格

- 直接把档位命名为“满意/不满意”并当主观事实；
- 用其他搜索数据表的点击总计数或明细行硬拼本会话 gold，却没有实测 join 证明；
- 没有真实曝光机会仍构造“有曝光未点击”；
- 用页面停留时长的任意阈值覆盖固定三档；
- 把未点击当负反馈或永久无需求。
