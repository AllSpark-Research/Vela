# organic_search_post_click_stage：搜索点击后漏斗阶段预测

## 一句话定义

给定自然搜索 query 与被点击 Note，预测该次点击后最深可观察行为阶段所在的合理范围。

## 出题条件

- 同一搜索会话 + `note_id` 有真实点击，并有可靠商品浏览、加购、立即购或成交字段。
- gold 取单调阶段：仅点击 < 商详浏览 < 加购或立即购买 < 下单；字段缺失不等于零。页面停留时长是用户×Note 聚合值，不作为本次请求 dwell gold。
- user behaviors 只包含点击前历史；题面可以披露 query 与“该 Note 已被点击”这一公共条件，但不得披露点击后的阶段字段。
- 结果窗口不完整、阶段字段冲突或无法确认同一搜索链路时不出题。

## 题目怎么问

Composer 明示阶段定义和预测窗口，要求输出一个连续阶段范围。范围可以退化为单一阶段，也可以包含
两个相邻阶段；不得跨级、不得把全部阶段都选上。若同时问多个点击 Note，每项独立评分后取宏平均。

## 可用信息

不得用聚合页面停留时长构造本次停留阶段；不得把未成交解释成
不喜欢，也不得把加购升级为成交。

## 回答与评分

支持单标签、编号表格或键值映射。hidden gold 仍是一个真实最深阶段：gold 不在范围内得 0；gold 在
单阶段范围内得 1；gold 在两个相邻阶段范围内得 0.75。多个对象取宏平均。不能把排序模型分
当监督。

## 可选变化

难度来自相邻漏斗阶段、同 query 下多个点击对象、历史强意图与本次浅行为的冲突。

## 种子提示词

题面会提供冻结的可见历史、明确的预测窗口以及题目所需的候选或状态定义。请根据搜索 query、候选内容和冻结历史，预测点击后的响应阶段范围。输出题面定义的相邻阶段或阶段区间，不把点击直接升级为深度互动、商业意图或成交。只使用题面给出的信息，不得新增、删除、改写候选或使用未披露的未来结果。
## 不出题/不合格

没有可靠的点击对象、预测窗口或后链路阶段结果时不出题；跨越不相邻阶段、泄漏真实结果或升级动作含义，均不合格。
