# organic_search_candidate_selection：自然搜索结果候选选择

## 一句话定义

给定一次真实搜索的 query、结果候选及排名，预测用户会点击哪些 Note。

## 出题条件

- 同一搜索会话下有 query、完整真实曝光候选和排名；候选集包含该请求能可靠关联的全部真实曝光，不因是否点击而增删。
- 完整真实 Note 曝光候选集合去重后最多 30 张；超过 30 时不得按点击 gold 截取，本模板直接不出题。
- gold 是该搜索窗口内、且位于固定候选池中的真实点击 `note_id`；候选构造不得读取 future user behaviors 中的动作。
- 未点击只表示该次未选择，不等于不喜欢或负反馈；Note 内容按 `note_id` 集中加载。
- query 缺失、候选无法同会话对齐、点击项不在完整候选池中或真实曝光候选集合不完整时不出题。

## 题目怎么问

题面给出 query 和匿名编号候选，可包含真实排名但不泄漏点击字段。每个 Note 候选展示标题、正文及所有非空图片描述、视频描述，暂不展示 OCR 或 ASR 字段，完整曝光候选集合去重后最多 30 张。要求选择会点击的全部候选；不得
把上游排序分、模型分或位置直接写成 gold。

## 可用信息

候选规则对点击与未点击完全相同；不能加入未曝光随机
Note，不能把低排位或未点击解释成低质量。

## 回答与评分

使用编号/字母集合、排序列表或 JSON 数组均可，由题面明确。点击集合按 precision/recall/F1；若要求
顺序，只在真实点击顺序可靠时另算排序分。

## 可选变化

使用同 query 下真实近邻候选、标题相近但对象不同的 Note 和位置偏差形成难度。

## 种子提示词

题面会提供冻结的可见历史、明确的预测窗口以及题目所需的候选或状态定义。请根据搜索 query、冻结历史和题面给出的真实有界候选，预测用户会点击的 Note 集合。只能从题面候选中作答；曝光未点击不等于不喜欢，点击也不等于深度兴趣。只使用题面给出的信息，不得新增、删除、改写候选或使用未披露的未来结果。
## 不出题/不合格

没有可靠的 query、完整曝光候选或可审计点击结果时不出题；把未曝光 Note 混入候选，或把未点击解释为负反馈，均不合格。
