# creator_next_publish_topic：下一创作主题预测

## 一句话定义

根据用户既往发布内容和其他可见行为，预测未来发布 Note 的主题或内容类目，而不是复原未来原文。

## 出题条件

- user behaviors 中至少有两条可读的“发布笔记”事件或稳定创作线索；future user behaviors 中有真实发布 Note。
- gold 从完整预测窗口内**所有有效 future user behaviors 发布 Note**抽取同一明确层级的主题、类目或内容标签，并按规范化值去重。
- 候选来自同层主题池，包括历史主题近邻和相邻内容方向；未来 gold 全部排除出干扰项。
- future user behaviors 中的 Note 缺少可读主题、层级混乱或合法干扰少于 2 个时不出题；干扰目标数在 gold 数 `P` 到 `2P` 之间随机，数量不足时使用全部现有候选。

## 题目怎么问

Composer 明示预测窗口、主题层级和封闭候选，要求选择窗口内出现的全部主题。gold 只有一个时只是单元素集合。题目只能预测主题/类目，不要求模型
编造标题、正文、创作动机或商业目标。

## 可用信息

难度来自同一大类下的细主题、旧主题与近期转向、跨发布与互动证据。不得凭空加入热点凑候选，也不
把一次浏览写成确定创作计划。

## 回答与评分

使用标签集合、编号集合或有界自然语言；隐藏评分按集合 precision/recall/F1。候选总数和作答数量不设模板级上限。若允许一句理由，只按 user behaviors
证据对应性评分，不把常识扩写当正确。

## 可选变化

可以改变主题层级、历史主题与近期转向的比例以及候选近邻程度，但不能要求复原未来标题、正文或创作动机。

## 种子提示词

题面会提供 <user behaviors>、明确的预测窗口以及题目所需的候选或状态定义。请根据 user behaviors 中用户本人此前发布的内容，预测窗口内本人可能发布的主题集合。只使用本人作品与明确创作线索，不得把互动过的他人内容或外部热点当作创作计划。只使用题面给出的信息，不得新增、删除、改写候选或使用未披露的未来结果。
## 不出题/不合格

证据、候选或 gold 无法闭环，目标无法可靠对齐，或题目要求凭空推断时不出题。
